# 岗位匹配与收藏反馈验收

更新日期：2026-10-08。

## T10 岗位筛选与推荐

学生“寻找岗位”可组合关键词、专业、技能、城市和希望实习日期；技能以逗号分隔，筛选要求岗位包含所有指定技能。专业未设要求的岗位仍可显示；指定日期时仅显示起止日期明确且覆盖申请日期的岗位。

`GET /api/portal/jobs?q=&major=&skills=&city=&from=&to=&page=1&size=10` 返回分页结果，日期倒置及超长条件返回 400。只展示企业与岗位审核通过、已发布且尚未截止的岗位。

`GET /api/portal/recommendations` 使用学生本人档案；学校管理员须提供 `studentId`。原 `GET /api/recommendations?studentId=` 已替换 501，保留学校管理员入口。本校及本人范围校验失败返回 404，招聘人员不能查看学生推荐。

规则评分：专业 30、技能 30（按具备比例）、地点 15、时间 20、到岗天数 5。无冲突优先，同组按分数降序、岗位 ID 升序，最多 100 条。专业及技能按逗号、中文顿号或分号分隔的完整词项匹配，JavaScript 不等于 Java。专业“计算机相关专业”不会自动推断覆盖其他专业；需岗位维护人员明确列出接受的专业。时间需学生档案覆盖岗位全程；未知日期展示待确认，不假设已匹配。分数不代表录用概率。

验证：前端语法、12 项测试；MySQL verify 62 项，无失败、无跳过并成功构建。回归覆盖组合筛选、完整适配 100 分、各类冲突、技能边界、缺失档案、下架/截止排除和跨学生/学校访问。事务测试回滚。

候选 JAR 于本机 8082 启动；真实浏览器学生组合筛选 `Java + 计算机 + Java,MySQL + 上海` 返回 1 条岗位，推荐展示理由、技能缺口及专业/地点冲突、日期缺失。截图保存在忽略目录 `.local/matching-verified.png`。

## T11 收藏与反馈

学生“岗位收藏”支持本人分页查看和取消，重复收藏为幂等操作。岗位下架后保留收藏供查询，新增收藏和新反馈只接受开放岗位；投递仍重新校验开放状态。

`PUT /api/portal/favorites/{jobId}` 收藏，`DELETE` 取消，`GET /api/portal/favorites` 分页查看；`POST /api/portal/feedbacks` 提交 NOT_INTERESTED / NOT_SUITABLE 及原因；`GET` 分页查询本人或本校反馈；`POST /api/portal/feedbacks/{id}/handle` 本校管理员保存核查答复。新增 `match_feedback_resolution` 表保留办理人、结果和时间，已有记录不覆盖，重复办理返回 400。

验证：同一轮 MySQL verify 62 项及前端 12 项通过；回归覆盖重复收藏、取消他人收藏不影响本人、下架收藏查询、学生和跨校管理员越权、答复通知及重复办理。

真实浏览器学生收藏 Java 演示岗位，列表保存 1 条；学生提交专业不匹配反馈 → 学校管理员办理并显示核查答复与“已办理”。演示数据不含真实个人信息，截图 `.local/feedback-verified.png`。最终候选重启后，收藏 1 条、反馈答复及本人推荐继续可读；见 [总览](third-priority-workflow.md)。
