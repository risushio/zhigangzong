# 三方评价与评分规则验收

2026-10-08，T07 已验证。学校按批次配置学生自评、企业评价、教师评分权重和及格线，权重合计 100%；未配置或三方当前评价未提交齐时不计算总成绩。评分、权重和及格线为 0–100、最多两位小数，加权总分按两位小数四舍五入。
