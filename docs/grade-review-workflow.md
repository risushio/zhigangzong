# 成绩复核与补充重提验收

2026-10-08，T08 已验证。三方评价与规则就绪后学生申请学校复核，保留首次及每次申请的完整评分、评价人、规则版本、权重、及格线和总分。学校确认成绩、拒绝本次申请或指定 STUDENT/ENTERPRISE/TEACHER 退回补充；学校不直接改分。指定评价人修改并提交后，学生重新提交复核。退回申请可由学校拒绝关闭。

同一实习待审/退回复核互斥。评分、导师或规则版本变化时不能执行旧快照；须退回核对或拒绝后重新申请。新的复核申请在处理中时，当前成绩不作为已复核成绩；拒绝新申请不撤销仍有效的既往批准结果。终止/替代实习只查历史。

接口：GET/POST `/api/portal/placements/{id}/grade-reviews`，GET `/api/portal/grade-reviews/{id}`，POST 同路径 `/resubmit` 和 `/review`。写请求使用 Session/CSRF。复核体包含 decision、comment、returnTypes；退回必须选不重复的评价方，其他决定不得携带退回方。

前端语法和 12 项测试、MySQL Maven verify 55 项无跳过及构建、29 项查询与登录注销通过。浏览器实习 407 学生申请 → 学校退回教师 → 教师补充将 85 改为 90 → 学生重提 → 学校批准，保留原总分 85.50 和新总分 88.00 的四条快照。自动化另覆盖互斥、旧规则拒绝、退回类型校验、拒绝新申请保留旧有效结果、角色/学校和终止边界。截图 `.local/grade-review-workflow-verified.png`；合成资料与凭据留在忽略目录。
