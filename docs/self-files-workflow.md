# 自主申报与私有文件管理

更新：2026-10-07。当前项完成后按用户要求暂停开发，后续从 NEXT-STEPS 继续。

## 学生自主申报

学生登录，在“审批与过程跟踪 → 自主实习申报”选择本学院批次，填报自行联系的单位、单位代码、联系人、电话、地址、岗位、工作内容和实习日期。保存形成 SELF 草稿，不经过招聘录用。日期须在批次内；每个学生每批次当前只能有一条实习记录。

单位代码已在企业库存在时，校验全称并引用原企业，学生填报的联系人、地址和岗位另存申报快照，不改写企业资料。新单位会建立 PENDING 企业供学校核验；批准本次实习不会自动把企业全局改为 APPROVED。暂停合作或未通过审核的单位不能提交/获批。

学生可在“实习材料”上传协议、保险等资料，再打开“详情与审批 → 提交自主申报审批”。学校管理端沿用现有批准/退回/拒绝入口。退回后学生补充申报和文件，保存后再次提交。每次保存和提交的单位、联系人、地址、岗位、日期、内容、操作人及时间都保留快照，原审批意见保留。

获批后可按已有流程分配本校教师与所属企业导师，进入到岗和周报流程。已提交/批准的申报不能直接改写；实习期间换岗/换单位仍待后续变更审批实现。

## 文件与材料

- “我的简历文件”上传个人简历；投递时明确选择某个上传文件，招聘方才取得本次分享的文件访问权。其他招聘企业无法访问；学生撤回申请后，相应招聘访问终止。原简历引用字段仍兼容。
- 每条实习的“实习材料”支持 AGREEMENT、INSURANCE、RESULT、OTHER。上传新增独立文件，补充版本不覆盖旧文件。老师和学校管理员可审核通过/退回并保留意见历史；企业导师可读其指导实习材料，无材料审核权限。
- 单文件上限 10 MB；支持 PDF、PNG、JPG/JPEG、UTF-8 TXT、无宏 DOCX。校验名称、格式特征、图片尺寸和 DOCX 展开限制；拒绝路径分隔符/控制字符、空文件、格式不符、超限上传。
- PDF 使用离线 Mozilla PDF.js 5.6.205 逐页绘制到 canvas，避免依赖内置浏览器 PDF 插件；字体/CMap/worker 均随应用提供，不从 CDN 加载。图片和文本可预览，DOCX 下载后查看。
- 预览和原件下载都检查登录、学校、所有者或当前指导关系；下载设置 no-store、nosniff 和安全 Content-Disposition。存储使用随机文件名，元数据响应不输出存储路径。读取时验证字节数与 SHA-256；缺失/损坏文件返回可理解的 503 错误。
- 实习材料同步现有 internship_material，上传、文件访问、审核和业务提交写审计；审核结果通知本人。数据库事务失败会清理本次新建文件，不涉及既有上传文件。

文件元数据与业务保存在本机 MySQL，原字节保存在忽略的 `.local/uploads/`。备份/迁移须同时保存数据库与该目录。生产环境的病毒扫描、配额、保留期限、备份恢复策略仍待完善；目前不提供删除文件的入口。

## 新接口

统一 `/api/portal`；沿用 Session + 动态 CSRF，文件上传为 multipart/form-data。

| 方法与路径 | 用途 |
| --- | --- |
| POST /self-placements | 学生建立自主申报草稿 |
| PUT /self-placements/{id} | 本人修改草稿/退回申报 |
| POST /self-placements/{id}/submit | 本人提交/重新提交 |
| GET /placements/{id} | 包含自主申报资料、快照和原审批历史 |
| POST /placements/{id}/approval | 本校管理员独立审批（沿用） |
| POST /files | 学生上传；file、kind、可选 placementId |
| GET /files | 本人简历分页，或按 placementId 查询范围内材料 |
| GET /files/{id} | 文件元数据、审核历史 |
| GET /files/{id}/preview | 范围内 PDF/图片/文本预览字节 |
| GET /files/{id}/download | 范围内原件下载 |
| POST /files/{id}/review | 当前教师或本校管理员审核实习材料 |
| POST /applications | 新增可选 resumeFileId，要求本人已上传简历 |

新增 self_placement_detail、self_placement_event、stored_file、application_resume、file_review_event，共 5 张表，数据库累计 34 张表；未修改既有表结构、未删除既有数据。前端新增 self-placement.js、files.js、pdf-preview.js，继续复用原生模块、公共表单/弹窗/表格及原有主题。

PDF.js 的 Apache-2.0 许可与来源说明保存在 `src/main/resources/static/vendor/pdfjs/`；该渲染库为离线文件预览用途，没有引入新的前端应用框架。
