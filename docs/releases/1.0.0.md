# 智岗踪 1.0.0

发布日期：2026-10-07。版本标签：`v1.0.0`。

本版本是面向单校本地试点的可运行版本，采用 Java 17、Spring Boot、MyBatis、本机 MySQL 与原生 JavaScript，保留深蓝黑粒子主题。

## 已实现

- 管理员、学生、招聘人员、教师及企业导师登录和对应工作空间。
- 企业与岗位维护、审核、发布及下架；学生档案和招聘申请、面试、录用、确认。
- 独立学校审批、退回补充重提、状态历史及通知已读。
- 双导师分配和改派、指导关系访问控制、企业导师确认到岗。
- 学生周报草稿、提交、教师批阅或退回、修改重提及独立历史快照。
- 自主实习申报、学校审批和申报快照。
- 私有简历与实习材料上传、PDF/图片/文本预览、原件下载、材料审核和投递简历授权。

## 验证与运行

已完成 32 个后端测试、12 个前端测试、语法检查和 29 个基础接口查询及登录注销验证。真实浏览器已验证招聘审批、导师到岗周报、自主申报与文件审核流程；重启后 MySQL 记录和本地文件仍可读取。详细记录见 [交接清单](../NEXT-STEPS.md)。

运行需要 Java 17、Maven 和 MySQL；首次安装按 [本地运行说明](../local-workflow.md) 配置 `.local/application-local.properties` 和首个管理员。数据库会通过项目 schema 初始化，已有数据不会清空。源码运行入口为 `.\scripts\start.ps1`，访问 `http://127.0.0.1:8080/#/login`。已下载的可执行 JAR 可在配置好的项目目录运行 `java -jar zhigangzong-1.0.0.jar`。

源码和发布产物不包含本机数据库、密码、演示账号凭据或上传材料。上传文件位于 `.local/uploads/`，备份时应同时备份数据库。

## 当前边界

历史管理接口尚未全面实现多学校隔离，本版本不能视为完整多租户系统。推荐接口仍返回 501。考勤与变更、异常处理、评价归档、提醒统计、Excel 导入导出、账号完善及全面移动端与分页回归仍待开发。DOCX 支持下载，暂不在线渲染。

第三方 PDF.js 5.6.205 使用 Apache-2.0 许可证，其许可证和说明保留于 `src/main/resources/static/vendor/pdfjs/`。
