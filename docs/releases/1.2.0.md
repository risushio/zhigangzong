# v1.2.0

发布日期：2026-10-08。版本标签：`v1.2.0`。

智岗踪 1.2.0 完成第三优先级 T10–T15，将岗位选择、学校执行规则、截止待办和批次数据汇总接入现有实习流程，继续面向单校本地试点。

## ✨ Features

- **岗位匹配：**组合筛选专业、技能、城市和实习日期；展示适配分、推荐理由、缺失技能及时间、地点、到岗天数冲突，排除未开放或已截止岗位。学生查看本人推荐，学校查看本校学生推荐。
- **执行规则：**按学院、专业及批次配置初始学校批准条件、周报周期、默认签到、必需材料和评分要求，保留版本历史并用于实际校验及结项。单实习签到设置和独立批次评分仍优先生效。
- **学生 Excel：**学校管理员下载模板、导出本校学生档案，先校验再整批导入已有本校学生用户的新档案。返回逐行错误，任一错误整批不写入；不覆盖已有档案，保留学号前导零，拒绝公式、宏和外部链接。

## 🚀 Improvements

- 学生收藏与取消收藏岗位、提交推荐反馈；学校核查答复并通知学生，保留办理人和时间。
- 按规则定时生成材料与周报截止提醒并去重；通知分别记录已读和待办完成状态，手动完成待办不代替业务办理。
- 按批次展示落实率、完成率、专业匹配和材料缺失，列明统计分母、未知与未配置项；每位学生只统计最新有效实习安排。
- Maven、前端包和启动脚本统一为 1.2.0。

## 运行与升级

需要 Java 17、Maven 和 MySQL。配置见 [本地运行说明](../local-workflow.md)。在项目根目录执行 `.\scripts\start.ps1`，或在已配置的项目目录执行 `java -jar target/zhigangzong-1.2.0.jar`。

升级前同时备份数据库和 `.local/uploads/`。本版本新增范围规则及其版本事件、反馈办理和截止提醒表，启动时按项目 schema 初始化。旧批次仍可使用原有预警规则和独立评分配置；学校需按实际制度配置新范围规则。源码不包含本机数据库、账号密码或上传文件。

## 当前边界

推荐采用可解释规则和明确专业词项，最多返回 100 项；统计分母为当前学院已开通学生，并非冻结历史名册。Excel 当前支持学生档案，不创建账号。范围规则调整初始批准条件，审批仍由学校管理员办理。截止提醒仅在应用内生成，未连接外部消息渠道。账号完善、学院管理员及历史管理 API 的全面学校隔离仍待开发；DOCX 仅支持下载。

## 验证

发布候选的前端语法检查及 12 项测试通过；显式启用 MySQL 的 Maven verify 66 项全部通过，零失败、零错误、零跳过，可执行 JAR 构建成功。通过更新后的启动脚本在独立回环端口运行 1.2.0 候选，基础查询、登录注销及新增业务接口验证通过，历史归档与原文件核对通过。
