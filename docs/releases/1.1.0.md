# 智岗踪 1.1.0

发布日期：2026-10-08。版本标签：`v1.1.0`。

本版本在 1.0.0 的招聘审批、自主申报和双导师过程管理基础上，增加考勤与实习变更、求助和规则预警、三方评价与成绩复核，以及结项档案冻结和 ZIP 导出，继续面向单校本地试点。

## ✨ Features

- **考勤与请假：**按实习启用签到，支持单日请假、补签、教师审批与退回重提，保存原因、意见及历史；默认不要求签到。
- **实习变更：**支持延期、换岗、换单位和终止的学校审批。重新安排建立关联新记录，原资料与历史保留，终止或被替代的记录只读。
- **求助与预警：**支持学生求助、责任分派、跟进结果、学生确认和学校复核；按批次配置并主动检测未落实单位、材料逾期、周报缺交及长期未联系，保存触发依据并去重。
- **三方评价与复核：**支持学生、企业导师和教师评价，学校显式配置批次权重和及格线；支持成绩复核、指定评价方补充重提及历次评分快照。
- **结项与归档：**核查结束日期、已复核及格成绩、过程办结、预警与材料后办理结项。批准后冻结档案，学生本人和本校管理员可导出元数据及原文件 ZIP。

## 运行与升级

需要 Java 17、Maven 和 MySQL。配置与首个管理员初始化见 [本地运行说明](../local-workflow.md)；在项目根目录运行 `.\scripts\start.ps1`，或在已配置的项目目录执行 `java -jar target/zhigangzong-1.1.0.jar`。

升级前同时备份 MySQL 数据库和 `.local/uploads/`。本版本增加业务字段及历史表，启动时按项目 schema 初始化，不清空已有业务数据；源码不包含数据库、账号密码或上传文件。评分规则需由学校按批次配置，未配置或三方评价未齐时不计算总分，也不能结项。

## 当前边界

预警由学校主动执行检测，不包含后台定时推送。智能推荐接口仍返回 501；岗位收藏、统一流程配置、截止提醒与待办完成状态、业务统计、Excel 导入导出、账号完善、学院管理员及历史管理 API 的全面学校隔离仍待开发。DOCX 支持下载，暂不在线渲染。
